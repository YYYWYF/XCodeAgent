# 工作台原型领域规则

本文档只描述 `prototype/` 演示工程中的工作台状态、交互限制和剧本约束，不作为正式工程的架构规范。

## 核心层级

**应用**：用户持续维护和迭代的软件工程，是版本链的根。

**版本**：应用在一次完整制作周期结束后形成的不可变资产快照。版本生成后，原型中的所有产物、对话输入和工作流操作均应只读；新变更只能发生在后续迭代版本中。

**阶段**：单个版本内依次发生的设计、开发、审查状态，每个阶段只允许调度其专属 Agent。进入后续阶段后，前序阶段产物只读；回退阶段需要二次确认，向后推进不需要确认。

**产物**：SDD 流程要求完成的正式应用资产，包括需求文档、项目计划、页面、接口和审查报告。产物状态统一为未开始、进行中、已完成。

## 对话与产物

**对话**：承载 Agent 上下文和工作流的 Session。一个对话可以生成并拥有多个产物，也可以只读引用其他产物。

**默认对话**：持有某个产物唯一编辑权的对话。从产物树选择产物时，应进入该产物的默认对话；多个产物属于同一默认对话时，选择它们不应切换到不同对话。

**计划内正式对话**：设计阶段的“应用设计”和项目计划指定的首个开发对话由系统预先创建。预建只确立产物归属，不代表产物已经开始；用户首次发送消息时，相关产物立即进入进行中。用户自由新建的其他对话仍在收到 Agent 回复后才进入目录。

**产物写锁**：一个产物只能由其默认对话编辑。其他对话可以把该产物作为消费上下文读取，但不能修改。

## 原型权限优先级

产物访问状态按以下顺序判定：

1. 尚未到达产物所属阶段：不可用。
2. 当前版本已经生成或正在查看历史版本：只读。
3. 当前工作台不在产物所属阶段：只读。
4. 当前对话不是产物的默认对话：只读。
5. 以上限制均不存在：可编辑。

## 演示剧本约束

“实现我的回检”是一个对话拥有多个产物的主要演示案例。该对话同时负责：

- 页面“我的回检”；
- 接口 `GET /api/rechecks/my`；
- 页面调用接口后的联调验证。

从页面或接口产物进入时，都必须打开同一个“实现我的回检”默认对话。对话顶部与右侧产物区域都必须同时呈现页面和接口，工作流也必须体现接口实现、页面实现以及调用联调的先后关系。

开发详细设计文档按对话生成，一条开发对话只对应一份联合设计文档；页面与接口代码仍按各自文件分别展示。
